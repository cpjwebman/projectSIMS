System API

Authentication, endpoints, request validation, response formats, and error handling for the application's JSON API.

Base path: /api

Authentication: Laravel Sanctum bearer token

Source: routes/api.php, API student controller, resource, and feature tests

1. Scope and conventions

The current API exposes CRUD endpoints for student records and a signed-in-user endpoint. It does not expose API resources for courses, subjects, year levels, or enrollment management. Web enrollment workflows are documented separately.

  • Use JSON requests and responses with Accept: application/json.
  • Student resources are under /api/students.
  • Student resource routes are named api.students.*.
  • IDs are database record IDs; student number is a separate unique business identifier.

2. Authentication and authorization

All student endpoints require auth:sanctum and the role:admin,staff middleware. The token must belong to a user with admin or staff role whose account is active. Role-denied/inactive requests return 403; unauthenticated requests return 401.

Authorization: Bearer YOUR_SANCTUM_TOKEN
Accept: application/json
Content-Type: application/json

This application does not define a route to issue API tokens. Token provisioning must use an approved Sanctum token-issuing mechanism outside this API reference. Never place tokens in source control or client-side public code.

5. Create student

POST /api/students
Content-Type: application/json

{
  "student_number": "STU-1001",
  "first_name": "Avery",
  "last_name": "Morgan",
  "email": "avery@example.com",
  "course_id": 1,
  "year_level_id": 1,
  "phone": "555-0101",
  "date_of_birth": "2005-04-12",
  "address": "12 College Road"
}

Returns 201 Created with a JSON resource and eagerly loaded course/year-level values.

6. List and retrieve

GET /api/students returns a Laravel paginated resource collection sorted by last name, then first name. Pagination follows Laravel's standard data, links, and meta format. The current list endpoint has no search/filter query parameters.

GET /api/students?page=2

GET /api/students/{student} uses route model binding. A missing student returns 404.

7. Update and delete

PATCH /api/students/42
{
  "student_number": "STU-1001",
  "first_name": "Jordan",
  "last_name": "Morgan",
  "email": "jordan@example.com",
  "course_id": 1,
  "year_level_id": 1
}

Update returns the refreshed student resource. Delete returns 204 with no response body. The API delete controller does not apply the web controller's explicit enrollment-history guard; relational database constraints determine whether related data prevents deletion. Review that behavior carefully before using delete on production records.

8. Student resource shape

{
  "data": {
    "id": 42,
    "student_number": "STU-1001",
    "first_name": "Avery",
    "last_name": "Morgan",
    "email": "avery@example.com",
    "course_id": 1,
    "course": {
      "id": 1,
      "course_code": "BSCS",
      "name": "Computer Science"
    },
    "year_level_id": 1,
    "year_level": {
      "id": 1,
      "year_level": 1,
      "name": "First Year"
    },
    "phone": "555-0101",
    "date_of_birth": "2005-04-12",
    "address": "12 College Road",
    "created_at": "2026-11-07T04:00:00.000000Z",
    "updated_at": "2026-11-07T04:00:00.000000Z"
  }
}

Nested course and year-level objects are included when those relations are loaded by the endpoint. Sensitive login fields such as password are not part of StudentResource.

9. Errors and status codes

StatusMeaningTypical cause
200SuccessList, show, update, or authenticated user request.
201CreatedStudent created.
204No ContentStudent deleted.
401UnauthenticatedMissing or invalid bearer token.
403ForbiddenInactive account or account role not allowed.
404Not FoundBound student ID does not exist.
422Validation failedMissing/invalid fields, duplicate student number, or nonexistent course/year level.

Laravel validation errors are returned as JSON when the client sends Accept: application/json; the standard response includes a message and field-keyed errors object.
